# lrcbart implementation notes

Package built 2026-09-09 from method_spec.md v2 (Phase 1b). This file lists every place where the spec left a choice open and how it was resolved, every deviation from the spec with its reason, and the findings from the unit tests that bear on the spec.

## Layout

- `src/lrcbart.cpp`: one `Tree` class shared by both ensembles, an `Ensemble` struct with the f or g flag, the sampler (`lrc_sampler_cpp`), prediction from serialized forests (`predict_forest_cpp`), the estimand-level discrepancy variance (`forest_gvar_cpp`), the c_g Monte Carlo (`cg_montecarlo_cpp`), and exported leaf-level helpers for the unit tests (`f_leaf_logmarg_cpp`, `g_leaf_logmarg_cpp`, `g_leaf_pspike_cpp`, `g_leaf_draw_cpp`, `update_tau0_cpp`, `update_tau1_cpp`, `update_w_cpp`, `rtnorm_lower_cpp`).
- `R/lrcbart.R`: `lrc_bart`, `lrc_bart_aft`, `bart_fit`, `predict.lrcbart`, `lrc_discrepancy`, `lrc_borrowing_map`, `lrc_cg`, `lrc_ess_calibrate`, `lrc_ess_prior`, `lrc_ess_realized`, `lrc_ess_map`, `lrc_ate`.
- `tests/testthat/`: the seven tests requested (spec Section G tests 1 to 7; the Table 1 gate, spec test 8, belongs to the harness).
- `../R/fit_lrcbart.R` (harness): `fit_lrcbart(dat, outcome, N_target, w_prior, ...)` returning the comparators' `make_fit()` object, and registered variants `LRC-BART-100/75/50`, `LRC-BART-Hg5`, `C-BART` (w = 1), `LRC-BART-w0`.

## Choices the spec left open

1. Tree moves and their probabilities. The spec names grow, prune and change. We use grow 0.3, prune 0.3, change 0.4 (no swap move). A stump proposes grow with probability 1, and the Metropolis ratio uses the actual move probabilities of the current and proposed trees. Change acts on a node whose two children are leaves and redraws its rule; its prior and proposal terms cancel, so its ratio is the likelihood ratio only.
2. Split rule prior and proposal. Uniform over the variables that still have an admissible cutpoint at the node, then uniform over the admissible cutpoints (the interval left by the ancestors on the same variable), for both prior and proposal, so the rule terms cancel in grow and prune as in bartMachine. Admissibility is defined on the cutpoint grid, not on the data, so that prior tree draws (single-arm g, c_g Monte Carlo) do not depend on outcomes.
3. Cutpoints. 100 equally spaced interior points on the range of each variable, as `BART::wbart` with `usequants = FALSE`; a variable with at most 100 distinct values uses the midpoints between consecutive distinct values (binary covariates get one cut). The grid is built from the pooled control covariates; the calibration builds it from the RWD and RCT profiles together.
4. Minimum leaf size. n_min = 5 on the leaf's own data as specified; a proposal that violates it is rejected. In single-arm mode the g ensemble has no data and n_min is set to 0 for g, so the g tree moves target the tree prior exactly (likelihood ratio 1).
5. Centering. y (or log time) is centered at its pooled mean before sampling; the range rules for lambda_f and tau1^2 are unaffected; predictions add the center back.
6. Residual-variance prior scale. sigma_g^2 ~ Inv-Gamma(nu/2, nu lambda_g/2), nu = 3, lambda_g from the source-specific OLS residual SD with P(sigma < sigma_hat) = 0.9, as in the paper (main.tex line 380 and 416); for censored data sigma_hat comes from a log-normal `survreg` fit on that source. Sources with fewer than p + 6 observations fall back to the sample SD.
7. Single-arm sigma_1^2. With no RCT controls sigma_1^2 has no data. Following spec Section F (sigma_1 = sigma_2 in the application) it is set equal to the current sigma_2^2 draw each iteration.
8. tau0^2 initialization: min(s0^2, tau1^2 / 2); w initialization: a_w / (a_w + b_w); all trees start as stumps with zero leaves; censored log times start at the censoring bound plus 0.1 sigma.
9. tau1^2 default s1^2 (only used when `update_tau1 = TRUE`): the range-rule value.
10. Stage-1 blocks for the Pr-rule: 20 consecutive blocks of the Stage-1 draws (50 draws each at n_draw = 1000), one V_mu^f per block; sigma_1^2 defaults to the block mean of the Stage-1 sigma_2^2 draws when no RCT estimate is given. The grid is 141 log-spaced points on [1e-6, 10]. The expectation over tau0^2 uses 4000 common chi-square draws across the grid, which keeps ESS_0 exactly monotone in s0^2 (T3). c_g uses 2000 prior trees.
11. Calibration edge cases. If no grid value reaches G >= q the largest grid value is returned with a warning; if the smallest grid value already does, `at_boundary = "lower"` is set and a warning is issued when N_target is at or above the ceiling sigma_1^2 / V_mu^f (feasibility condition of T3).
12. Survival estimands. The RMST uses the closed-form log-normal expression of main.tex eq. rmst-closed-form; the population median solves mean_i Phi((m - mu_i) / sigma) = 0.5 per draw by bisection. `lrc_ate` uses each arm's own sigma draw. The harness wrapper uses the harness's `standardized_draws()` instead so that the estimand code is shared with the comparators.
13. Prediction. Every kept draw stores its serialized forests (about 25 MB for 1000 draws at n = 400), so `predict` works at arbitrary new covariates after the fit; in-sample fitted values are also kept.
14. Realized ESS. The spec writes c_g sum_h tau^2_{z_h} with one indicator per tree. With per-leaf indicators the estimand-level variance of the discrepancy given the posterior partition is sum_h sum_l (n_l / N)^2 tau^2_{z_hl}, with n_l the number of the N RCT profiles in leaf l; `lrc_ess_realized` uses this exact form and also reports the spec's tree-level approximation (`mean_cg_approx`). V_mu^f comes from the calibration object stored in the fit; without one it is approximated by the variance of the fit's own f draws and flagged.

## Deviations from the spec, with reasons

1. tau0^2 update truncated to tau0^2 < tau1^2. The spec states (A1) tau0^2 < tau1^2 as an assumption and truncates the optional tau1^2 update but not the tau0^2 update. With tau1^2 fixed, (A1) can only be kept through the tau0^2 draw, so the scaled-Inv-chi2(nu0 + K0, .) draw is truncated to (0, tau1^2) by inverse-CDF sampling of the chi-square tail. The truncation never binds in practice (posterior tau0^2 is of order 1e-3, tau1^2 of order 1).
2. w is clamped to [1e-12, 1 - 1e-12] after its Beta draw so that log w and log(1 - w) stay finite; w = 0 and w = 1 exactly are reached only by fixing w.
3. The realized ESS is the per-leaf form of item 14 above rather than the literal tree-level formula.

## Findings from the tests that bear on the spec

1. Test 7 (spec test 3, Sc4-type DGP with delta = 2, H_f = 50, H_g = 10, n_1 = 100 RCT controls, n_2 = 300). B_Rc, the ATE bias, the control-surface bias in R^c and the mean g in each region meet the criteria (three seeds: mean B_Rc = 0.010, mean ATE bias = 0.070, mean |control bias in R^c| = 0.094, mean g = -1.95 in R^c and -0.16 in R). The compatible-region criterion B_R >= 0.5 is not met: B_R = 0.24, 0.46, 0.65 (mean 0.45) on the test's DGP, and 0.23, 0.65, 0.06 on the harness's Sc4 DGP (paper's f, sigma 1.5 and 1.8). The assertion is kept in the test file so that the failure stays visible.
2. Why B_R is below 0.5 at H_g = 10, and why this is the model and not the sampler. With the RWD fully compatible (Sc4 at delta = 0) the map is about 0.41 everywhere and the posterior spike fraction is 0.78, close to the prior w. Leaf-level diagnostics (`keep_leaf_stats = TRUE`) show the mechanism: the RCT-only residual mean in a g leaf is the sum of the RCT noise and of f's approximation error at the RCT profiles (pointwise RMSE 0.66 for the paper's f at n = 400), which is spatially correlated. A g tree that splits off a region where that error is 0.3 to 0.5 finds a slab leaf (RMS slab theta 1.07 under delta = 0), and that leaf offsets the residual means of the other trees (the stump trees, n_1 = 93, sit at |ybar| of about 0.3, ybar^2 / v_1 of about 6), so 8 percent of the time a stump goes slab and B(x) is 0 for every x in that draw. The per-leaf spike probability is then about 0.91 rather than the 0.95 the spec's T2 remark assumes, and 0.91^10 = 0.39. The sampler itself is validated separately: the g ensemble alone (H_f = 0, w = 0, BART's alpha, beta and leaf scale) reproduces `BART::wbart` with 10 trees (correlation 0.97 of posterior means, matching sigma and posterior SD), the f path reproduces wbart with 50 trees (test 4), and the leaf-level block draw matches T1 to Monte Carlo error (test 1).
3. Consequences to weigh in Phase 2. H_g = 5 raises B_R to 0.56 on the harness Sc4 seed 1 (0.23 at H_g = 10) with the same B_Rc and ATE; the spec lists H_g = 5 as a sensitivity. The go/no-go value 0.5 for B_R should either be lowered to about 0.35 for H_g = 10, or H_g = 5 promoted. A cleaner remedy inside the model would be to make the borrowing map robust to whole-ensemble slab events, for instance a map based on the posterior of g(x) itself (P(|g(x)| < c)), which the discrepancy draws already provide. None of this was changed in the code.
4. Realized ESS in partially shifted scenarios. A slab leaf covering half the RCT profiles contributes (1/2)^2 tau1^2 of about 0.75 to the estimand-level variance, so the realized ESS drops to a few units (0.5 to 2.4 in test 7) even though borrowing in R is intact. The pointwise map `lrc_ess_map` and the regional map summaries are the informative displays; the scalar realized ESS answers a different question (how much the RWD informs the whole-population control mean) and should be reported with that reading.
5. A single-replicate ATE-bias criterion of 0.1 is below the posterior SD (0.12 to 0.19), so test 7 averages three fixed seeds; the Monte Carlo SE of that mean bias is about 0.07.

## Post-verification fixes (2026-09-09, after reports/verification_phase1.md)

Every change made in response to the Phase 1 verification. Files touched: `R/lrcbart.R`, `tests/testthat/test-02-two-leaf.R`, `test-03-limits.R`, `test-07-sc4.R`, the harness wrapper `../R/fit_lrcbart.R`, and one addition to `../R/metrics.R` (item 6). The sampler (`src/lrcbart.cpp`) is unchanged.

1. sigma_1^2 in the calibration (verifier bug 1). `lrc_ess_calibrate()` gains `y_rct_ctrl`, `x_rct_ctrl`, `status_rct_ctrl` and `sigma1_method = c("bart", "residual")`. When RCT controls are given and `sigma1_sq` is not, sigma_1^2 is the posterior mean residual variance of a plain BART fit on the RCT controls alone (same `H_f`, `n_burn`, `n_draw`; 0.1 s at n = 100). The OLS rule of the sampler's residual prior (`"residual"`) was tried first and rejected as the default: on the paper's nonlinear f it gives 7 to 8 against a true 2.25, because the curvature of f stays in a linear residual, so it would put the calibration in the wrong units in the other direction. The BART estimate is noisy at n = 100 (1.2 to 2.8 over seeds, truth 2.25) but unbiased in level. With no RCT controls (single-arm) the Stage-1 posterior mean of the RWD residual variance is used, as before. The wrapper passes the RCT controls, so the prior ESS_0 and the realized ESS (posterior sigma_1^2) are now both in RCT units; the returned `sigma1_sq` and `sigma1_source` record which was used.
2. V_mu^f from the whole chain (bug 2). `V_mu_f` is now `var()` of the Stage-1 estimand draws over all `n_draw` draws (the reported value, the ceiling, and the value `lrc_ess_realized()` reads from the calibration object). The Pr-rule still needs a block distribution; the 20 within-block variances are kept only for their spread and rescaled multiplicatively so that their mean equals the whole-chain variance (`V_blocks`; the raw values are in `V_blocks_raw`). The dead line 281 was removed. Consequence: because the blocks are spread around the whole-chain level, ESS_0 at the smallest grid value (the mean over blocks of sigma_1^2 / V_b) can exceed the ceiling sigma_1^2 / V_mu^f by a few percent (Jensen); `ceiling` is the reference number.
3. Feasibility cap (bug 3). The ESS ceiling sigma_1^2 / V_mu^f is computed and returned as `ceiling`. If N_target is at or above it, N_target is capped at the ceiling (`N_target` in the output; the requested value in `N_target_requested`), `s0_sq` is the smallest grid value (the point-mass limit, the only prior that reaches the ceiling) and `ess_capped = TRUE`. One warning per calibration call when `warn = TRUE` (default); the harness wrapper passes `warn = FALSE` and records the flag in the fit's `ess$ess_capped` and `extra$ess_capped`, so a 200-replicate run does not emit a thousand identical warnings. Measured ceilings in RCT units on the harness data (single seeds): Sc1 73 to 93, Sc2 36 to 38, Sc4 (X5, delta 2) 80 to 88. N_target = 100 is therefore capped in most Sc1 replicates and all three targets collapse to the point-mass spike in Sc2; the development run reports the capped fraction per scenario and method.
4. Compatibility map (bugs 4, 5; verifier's map recommendation). `lrc_borrowing_map(fit, x_new, type = c("abs_g", "all_spike"), c = 0.5)`. The default `"abs_g"` is P(|g(x)| < c | data) from the discrepancy draws, c on the outcome scale for Gaussian fits and on the log-time scale for AFT fits (0.5 is one third of the Gaussian study's RCT residual SD). `"all_spike"` is the former ensemble-level map, kept as a diagnostic. The wrapper returns the `abs_g` map at the RCT control profiles as the fit's `map` (harness `map_R`, `map_Rc`, `map_all`; `map_c` argument, default 0.5) and the all-spike map in `extra$map_spike`. Tests 2 and 3, which check the ensemble-level limits (w = 0 and w = 1, the two-leaf spike/slab split), now call `type = "all_spike"` explicitly.
5. Test 7 uses the RCT controls in the calibration and the new map with thresholds 0.7 in R and 0.15 in R^c; it also prints the all-spike map, the ceiling and the cap flag. Result after the fixes (seeds 101 to 103): B_R 0.92 / 0.82 / 0.96 (mean 0.90), B_Rc 0.02 / 0.00 / 0.08 (mean 0.03), all-spike map in R 0.28 / 0.00 / 0.60, mean ATE bias 0.07, ceiling 79 / 93 / 98 (N_target 100 capped on all three seeds). Suite: 146 expectations, 0 failures.
6. Harness metrics (one addition to `../R/metrics.R`, needed so that the secondary map and the cap flag reach the summary CSVs, since the harness stores only the metrics row and not `extra`): `compute_metrics()` reads `extra$map_spike` (all-spike map, region means `mapspike_R`, `mapspike_Rc`), `extra$g_mean` (mean posterior g, `g_mean_R`, `g_mean_Rc`), `ess$ceiling` (`ess_ceiling`) and `extra$ess_capped` (`ess_capped`, which aggregates to the fraction of capped replicates); the six columns are NA for methods without them and are added to `aggregate_metrics()`'s mean list. Nothing else in `metrics.R`, and nothing in `dgp.R`, `comparators.R` or `harness.R`, changed.
7. Not changed: the N_target ladder (spec Section E) is kept as specified even where it is infeasible, so that the development run shows the collapse rather than hiding it; the spec's Sc4 criteria are evaluated as written in the go/no-go report, with the restated map criterion (P(|g| < 0.5): mean at least 0.7 in R and at most 0.15 in R^c) reported separately. The `seed + 1L` overflow noted by the verifier (probability 2^-31) is left as is.

## Phase 2b tuning (2026-09-09, after the development go/no-go run)

The development run (02-validation/dev_gaussian, R = 200) failed the Sc4 local-borrowing criteria: with H_g = 10, split prior (0.5, 3), the range-rule slab and w ~ Beta(4, 1), the posterior mean of g on Sc4 (X5, delta 2) was -1.68 in R^c (truth -2) and -0.26 in R (truth 0), the map P(|g| < 0.5) in R was 0.65, the control surface in R was 0.035 (SE 0.006) worse than BART-PP's, and the Sc3 bias was 0.06. This section records the diagnosis and the configuration change. All runs are in 02-validation/tuning_phase2b (run_factorial.R with stages ofat, combo, confirm, moderate; summary_<stage>.csv; the stage logs), on Sc4 (X5, delta 2) at R = 40 for the factorial stages and on Sc4 delta 1 and 2, Sc3 (rho 0), Sc1 and Sc5 (delta 2) at R = 60 for the confirmation, always paired with BART-PP on the same replicate data.

1. What was varied. H_g in {1, 2, 3, 5, 10, 20, 30}; split prior (0.5, 3), (0.95, 2), (0.95, 1); slab multiplier tau1_mult in {0.5, 1, 4, 16} on the range rule; g leaf minimum n_min_g in {5, 1}; five g sweeps per iteration; a warm start of g from a greedy depth-2 tree on the BART-PP-implied source offset; w ~ Beta(4, 1) against Beta(1, 1). The code gained the arguments n_min_g, tau1_mult, g_sweeps and g_init (with lrc_g_init_greedy() to build one) in lrc_core(), and the wrapper gained the same plus warm_start.

2. The delta 2 under-shoot is neither prior capacity nor mixing. One factor at a time from the baseline, every configuration gave g_R between -0.24 and -0.31 and g_Rc between -1.67 and -1.76 (summary_ofat.csv): H_g, the split prior, a slab up to 16 times the range rule and n_min 1 leave g where it is. The warm start (-0.29 / -1.72) and five sweeps (-0.25 / -1.75) leave it too, and a 5000-iteration burn-in on single replicates changes nothing, so the chain is not stuck. Oracle runs with f known (the true RWD surface subtracted from both sources, so g is fit to -2 1{R^c} plus noise) give g_R = -0.19 and g_Rc = -1.86 at H_g = 10 and -0.13 / -1.93 at H_g = 1 to 3 (24 replicates, SE 0.05): the g ensemble alone, with n_1 = 100 RCT controls, shrinks the contrast by 10 to 15 percent with the overall level intact. By distance from the boundary (24 replicates, H_g = 10, full model) the g error in R is -0.71 within 0.15 of X5 = 2, -0.37 at 0.15 to 0.3, -0.26 at 0.3 to 0.5 and -0.17 beyond 0.5; in R^c it is +0.45, +0.20, +0.16, +0.16. Two things produce it: the position of the g cut is learned from about four RCT controls per 0.1 of X5, and draws with the cut on the R side assign R points to the shifted leaf; and f, fit to the pooled data, smears the RWD step (the Stage-1 BART on the RWD alone is +0.24 too high in R and -0.17 too low in R^c within 0.3 of the boundary, unbiased farther away), which g then compensates. With the step removed from the RWD altogether (Sc1 data with the RCT controls shifted by -2 in R^c) the full model still gives -0.17 / -1.89, the g-side share. The criterion "mean g within 0.15 of the truth in both regions" is therefore not reachable by tuning g, and the paired surface loss in R against BART-PP (0.02 to 0.04, SE 0.01 to 0.014 in every configuration) has the same origin.

3. Moderate shifts (Sc3, Sc4 delta 1) are decided by a prior trade-off, and fewer trees make it worse. Fewer g trees improve Sc1 (RMSE 0.134 to 0.138 for H_g 1 to 3 against 0.149 at H_g = 10, BART-PP 0.186) and the Sc4 delta 2 map (0.74 to 0.80 against 0.67) but raise the Sc3 bias (0.115 / 0.071 / 0.066 / 0.060 for H_g 1 / 3 / 5 / 10, SE 0.04) and the Sc4 delta 1 bias (-0.141 / -0.085 / -0.074 / -0.053; RMSE 0.249 to 0.204 against BART-PP's 0.189). H_g = 3 with the (0.95, 2) prior, the best on the delta 2 map (0.80), was dropped for this reason (Sc3 bias 0.10, Sc3 map 0.17: deeper trees hide a global shift in the spike). The oracle at delta 1 (f known, 24 replicates) shows that the g ensemble alone recovers only -0.54 to -0.76 of a shift of -1 with map_Rc 0.31 to 0.55, for every H_g, slab and w prior, and the per-draw states of a single tree show why: the posterior mixes the detected state (a split at X5 = 2 with a slab at about -1.2) with stump states in which f absorbs part of the RCT shift (in one replicate 66 percent of draws are the stump, with f at -0.47 in R^c). This is a legitimate posterior mixture: the split-and-slab state pays the tree-rule prior (one specific cut among p x numcut, about 6.9 nats) plus the slab's Occam cost log(w / (1 - w)) + log(tau_1 / tau_0), which is comparable with the likelihood gain of a shift of 1 at 50 points per side; fewer trees raise tau_1 through the range rule and so raise the slab cost. A flat w prior lowers the cost by 1.4 nats and reduces the Sc3 bias (0.044 to 0.048 against 0.060) and the Sc4 delta 1 bias (-0.032 to -0.040 against -0.053), within Monte Carlo error at R = 60 but in the predicted direction; a slab at half the range rule does about the same (summary_moderate.csv).

4. Choice. H_g = 5, split prior (0.5, 3), slab by the range rule, n_min_g = 5, one sweep, w ~ Beta(1, 1). At R = 60: Sc1 RMSE 0.148 (BART-PP 0.186), Sc3 bias 0.044 (RMSE 0.289 against 0.284), Sc4 delta 1 bias -0.040 (RMSE 0.212 against 0.189), Sc4 delta 2 g -0.24 / -1.75, map 0.69 / 0.05, surface in R +0.025 (SE 0.011) against BART-PP, ATE RMSE 0.178 against 0.185, Sc5 bias -0.002 with map 0.01 (summary_confirm.csv, row H5_a0.5b3_t1_n5_w11). Every difference against the development configuration is within one to two Monte Carlo SEs at R = 60; the choice is the balance between the delta 2 map (which wants fewer trees) and the moderate-shift bias (which wants a cheap slab), and the v2 go/no-go run at R = 200 is the test of it. Package defaults changed accordingly (H_g = 5 in lrc_core, lrc_ess_calibrate, lrc_ess_map and lrc_g_init_greedy; a_w = b_w = 1; lrc_ess_prior reports at w = 0.5); the wrapper follows, registers LRC-BART-f90 / f50 / f25 (fractional targets, item 5) and LRC-BART-Hg10 (the development configuration) in place of LRC-BART-Hg5. Test 7 under the new defaults: B_R 0.95, B_Rc 0.01, g -0.08 / -2.04; suite 146 expectations, 0 failures.

5. ESS target as a fraction of the ceiling. lrc_ess_calibrate() accepts N_target = c("frac", p) (or list("frac", p)) for p times the ceiling sigma_1^2 / V_mu^f, computed after Stage 1; the calibration then proceeds as for an absolute target and never caps for p < 1. The returned N_target_spec keeps the request. Ladder for the paper: absolute targets 50 and 75 where feasible (Sc1, Sc3, Sc4, Sc5 ceilings 73 to 176, median about 120) and the fraction 0.9 in place of 100, which is infeasible in a quarter of Sc1 replicates; in Sc2 (ceiling about 22) every absolute rung collapses to the point-mass spike and only fractions separate the rungs, so the Sc2 ladder is 0.25, 0.5, 0.9. Recommendation for the paper: report the fractional ladder (0.25, 0.5, 0.9 of the ceiling) as the primary sensitivity in every scenario, with the implied absolute ESS_0 in the table, and keep the absolute 100 row as the criterion row because it is what the spec's go/no-go names; the development runs carry LRC-BART-100 / 75 / 50 and f90 / f50 side by side.

6. Open. The spec's Sc4 criteria on g (within 0.25, and the 0.15 asked for in Phase 2b) and on the surface in R (0.90 times BART-PP's, or paired no-worse) measure the f/g decomposition near a region boundary with 100 RCT controls, and no g configuration meets them; the manuscript should state the boundary-local nature of the leak (item 2), report the map and the surface comparison away from the boundary as well as over the whole region, and present the moderate-shift bias (item 3) as the price of the spike, against BART-PP's 0.036 in Sc3.
